## 🕳 踩坑记录

- **坑 5：文件冲突**
  用终端改完 `demo.py` 后，VS Code 会弹窗说“文件已在磁盘上被修改”。
  这是因为终端和编辑器同时改了同一个文件。解决办法是点“仍然保存”覆盖，或者以后固定只用一种方式改代码，别两头改。

- **坑 6：模型文件报错**
  报错 `FileNotFoundError: Unable to open file at pose_landmarker_full.task`。
  一开始看到一堆 C++ 报错完全看不懂。后来在 `demo.py` 里加了 `build_detector()` 来加载模型，缺失时直接打印一句大白话提醒下载。自己写的报错提示一定要让人能看懂。

- **坑 7：测试数据写错了**
  写 `squat_logic.py` 自测时，模拟了 29 帧深蹲，结果计数一直是 0。
  查了半小时才发现是自测的假数据算错了（髋/膝/踝三点在一条线上），导致算出来的角度永远是 180 度，永远进不了下蹲状态。以后遇到结果不对，先怀疑自测数据，再怀疑算法。

## 🧠 核心算法：为什么要两个阈值

算深蹲角度时，不能只用一个角度临界值（比如 90 度）来判断下蹲和站起。
因为人蹲到临界点附近时会晃动，如果只有一个阈值，程序会反复横跳，导致一秒钟计数好几次。

所以这里用了**迟滞状态机（双阈值）**：
- 下蹲时，角度要小于 **85 度**，才判定为“蹲下”。
- 站起时，角度要大于 **95 度**，才判定为“站起”。

两个阈值之间留了 10 度的防抖死区，这样就算在临界点附近晃，计数也不会乱跳。
